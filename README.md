O Eco-Twin: Eco-Monitoramento Urbano Inteligente com o Impacto dos 10% é um projeto que utiliza análise de dados e simulação preditiva para mostrar como uma redução de apenas 10% no consumo de água e energia pode gerar benefícios econômicos e ambientais para a cidade. Por meio de uma maquete física ou digital e de recursos visuais interativos, o projeto transforma dados de consumo em informações simples e compreensíveis, incentivando a conscientização sobre sustentabilidade e o uso responsável dos recursos naturais.
